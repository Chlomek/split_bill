# Split Bill 🧾

Jednoduchá Flutter aplikace pro rozdělení účtů, skenování účtenek a okamžité vyrovnání dluhů pomocí QR platby.

## 🚀 Funkce
- 📸 **Skenování i ruční zadání**: Automatické načtení položek z účtenky (AI / ML Kit) i rychlé ruční zadání výdajů.
- ⚖️ **Zjednodušení dluhů**: Automatický přepočet, kdo má komu kolik poslat.
- 💳 **QR Platba**: Generování standardního českého QR kódu (SPAYD) pro platbu přímo v bankovní aplikaci.

## 🛠️ Jak spustit
```bash
# 1. Závislosti
flutter pub get

# 2. Nastavení prostředí
cp .env.example .env

# 3. Spuštění
flutter run
```
